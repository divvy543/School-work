# 🔋 NASA Battery AI

ML-powered Battery Management System using real NASA Li-ion battery degradation data.

## 📁 Structure
- `app/`: Streamlit dashboard
- `src/utils/`: Data parsers and visualization logic
- `config/`: System settings
- `data/`: Raw .mat files storage

## 🚀 Quick Start
1. `pip install -r requirements.txt` 
2. `streamlit run app/main.py`
